evaluation: what has been measured?

native codex

Browser pilot: 4/4 task checks. Browser-to-image: partial, exact 16:9 failed.

fixed / static routing

Single eligible Pi route uses deterministic selection. A matched static-vs-Decisions benchmark is not measured.

decision-based routing

Recorded creative selection binds a predefined fal route. Valid selection is not routing accuracy.

Full end-to-end latency, cost per verified success, aggregate retry/fallback rate and handoff reliability: not measured. Different timing boundaries do not establish speedups. Provider estimates are not billed costs; host and Pi subscription costs remain unknown.

decision provider architecture

openai: Decisions selects only filtered, predefined route IDs; the route binds harness and model. gpt-6-luna selects routes, it does not execute them or discover models. decima-local: planned / experimental, no implementation or benchmark established here.
